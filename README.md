# Retail Sales Performance Dashboard

An interactive dashboard built with Python to analyze sales performance across multiple retail stores. The project focuses on monthly revenue, store comparisons and sales targets, making it easier to identify trends and evaluate business performance.

## Project Overview

This project was developed as a practical data analysis project, covering data cleaning, analysis, visualization and dashboard development.

Using sales records and store management information, the dashboard provides an overview of business performance throughout the year.

**Note:** All datasets used in this project are fictional and were created for educational and portfolio purposes.

## Features

- **Monthly Revenue Analysis:** Track revenue trends throughout the year for each store.
- **Store Performance Comparison:** Compare total revenue across different stores.
- **Revenue Variation:** Analyze percentage changes in revenue between months.
- **Sales Target Tracking:** Monitor monthly targets and identify which stores achieved their goals.
- **Interactive Filters:** Explore results by store, year and month.
- **Performance Indicators:** View key metrics through summary cards and interactive charts.

## Technologies Used

- **Python** – Main programming language.
- **Pandas** – Data cleaning, transformation and analysis.
- **Plotly** – Interactive charts and visualizations.
- **Dash** – Interactive dashboard development.
- **Jupyter Notebook** – Project development and analysis.

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/retail-sales-performance-dashboard.git
```

2. Open the project folder.

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Open `analise_organizada.ipynb` in Jupyter Notebook or VS Code.

5. Run the notebook cells in order.

6. Start the Dash application and access it through your browser at:

```text
http://127.0.0.1:8050
```

**Important:** Keep the CSV and Excel files in the same folder as the notebook so the data can be loaded correctly.
